# KOTOR UE5 — Windows Playtest Builds

Experimental Windows playtests of a fan-made Knights of the Old Republic recreation in Unreal Engine 5. Unreal Editor and project files are not required.

## Download and play

Latest: **[TEST9782](https://github.com/Rogue-Echo3/KOTOR-UE5-Test-Builds/releases/tag/test-9782)**

1. Download [Download-Helper-9782.zip](https://github.com/Rogue-Echo3/KOTOR-UE5-Test-Builds/releases/download/test-9782/Download-Helper-9782.zip).
2. Extract the helper into a writable folder with about **64 GB free**.
3. Run **Download KOTOR Test.cmd**. It downloads, verifies, joins and extracts the game.
4. Run **Start KOTOR Test.cmd** from the resulting game folder. Keep its files together.

Use Releases for game downloads. Code → Download ZIP contains instructions and helpers.

## This build

**TEST9782 restores the previous portraits for Trask, Carth, Bastila, Canderous, Jolee, T3-M4, HK-47, Mission and Zaalbar.** Keeps the new Juhani and all player portraits. All other Visual Resurgence textures, 4K movies and TEST9781 fixes are retained. Gameplay and combat animation code are unchanged; paired sword/saber choreography remains under review.

All54 restored portrait assets match the saved pre-upgrade versions and cold-exported pixels. Targeted packaged roster/party-selector, save-load, opening and Carth departure checks are documented. This is not a new uninterrupted full-campaign or all-hardware certification.

**Escape** opens Options; **F4/F5** quicksave/quickload. Change controls under Gameplay → Key Mapping.

## Saves and bug reports

Copy your old **UserData/Saved/SaveGames** into the matching new folder to retain progress. Keep the old folder as a backup. Personal saves and logs are excluded from downloads.

Use the [bug-report form](https://github.com/Rogue-Echo3/KOTOR-UE5-Test-Builds/issues/new?template=bug-report.yml). Include TEST9782, area, steps and result, relevant screenshots/video and the latest log from UserData/Saved/Logs. Remove private information before uploading.
