# KOTOR UE5 playtests

Windows playtests of our KOTOR 1 project in Unreal Engine 5.8. This repository
provides packaged game downloads and bug reporting; editable project files are
kept in a separate private repository.

## Latest build: TEST9790

TEST9790 repairs three KOTOR 1 playtest reports:

Restores friendly nonlethal duelists after the match, with old story-state recovery.
Frames the Hutt's face in close dialogue shots.
Expands usable Taris doorway travel, including Upper City North/South, with wall-clearance checks.

Download Download-Helper-9790.zip, extract it, and run Download KOTOR Test.cmd. Allow about 65 GB temporarily during setup; about 22 GB remains installed afterward. Download the revised helper to use automatic cleanup. This is a standalone complete package NOT the full UE5 project file.

Use the [bug-report form](https://github.com/Rogue-Echo3/KOTOR-UE5-Test-Builds/issues/new?template=bug-report.yml).
Include TEST9790, the area, steps, expected/actual behavior and screenshots or a
short video. The latest log is in **UserData/Saved/Logs**. Remove private details
before uploading it.
