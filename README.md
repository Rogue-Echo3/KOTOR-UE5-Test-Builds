# KOTOR UE5 — Windows Playtest Builds

Experimental Windows playtests of a fan-made Knights of the Old Republic recreation in Unreal Engine 5. Unreal Editor and project files are not required.



## Download and play

Latest: **[TEST9786](https://github.com/Rogue-Echo3/KOTOR-UE5-Test-Builds/releases/tag/test-9786)**

1. Download [Download-Helper-9786.zip](https://github.com/Rogue-Echo3/KOTOR-UE5-Test-Builds/releases/download/test-9786/Download-Helper-9786.zip).
2. Extract the helper into a writable folder with about **65 GB free**.
3. Run **Download KOTOR Test.cmd**. It downloads, verifies, joins and extracts the game.
4. Run **KOTOR UE5 Playtest.exe** from the resulting game folder. Keep its files together.

Use Releases for game downloads. Code → Download ZIP contains instructions and helpers.

## This build

TEST9786 adds Revamped FX and title-screen smoke, the Starboard droid crossing fix, Duros raid voice and sword clips, and workbench updates. Blaster shots, stealth and mines keep their existing presentation. The launcher uses large, high-contrast buttons and checks GitHub for available releases. The in-game Exit to Main Menu button returns to the title screen, the character menu uses translucent level-up buttons, and the workbench places upgrade components beside the item preview.

**Escape** opens Options outside cutscenes. **Left-click** advances dialogue. R no longer resets the game. Left-click advances only the active dialogue line. **F4/F5** quicksave and quickload. Change bindings under Gameplay → Key Mapping.

Packaged checks covered the Endar duel, South Apartments raid, Movies replay, and Force particles. Five Force lab fixture failures also occur in TEST9784. Individual campaign encounters still need their own checks.

## Saves and bug reports

Copy your old **UserData/Saved/SaveGames** into the matching new folder to retain progress. Keep the old folder as a backup. Personal saves and logs are excluded from downloads.

Use the [bug-report form](https://github.com/Rogue-Echo3/KOTOR-UE5-Test-Builds/issues/new?template=bug-report.yml). Include TEST9786, area, steps and result, relevant screenshots/video and the latest log from UserData/Saved/Logs. Remove private information before uploading.
